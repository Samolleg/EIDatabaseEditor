EI Database Studio 0.2.0-preview.1

Назначение
==========

Безопасный Preview-редактор database.res для «Проклятых Земель».

Запуск
======

1. Установите Microsoft .NET 9 Desktop Runtime (x64), если он ещё не установлен.
2. Запустите EvilIslands.DatabaseEditor.exe.
3. Откройте исходный database.res. Он используется только для чтения.
4. Сохраняйте результат только через «Сохранить копию…» в отдельную staging-папку.

Ограничения безопасности
========================

- приложение не перезаписывает открытую базу;
- приложение не сохраняет результат в каталог игры или Starter\MODS;
- существующий целевой файл не перезаписывается;
- приложение не устанавливает созданную копию в игру;
- установка и игровая проверка являются отдельными действиями пользователя.

Содержимое handoff
==================

Папка содержит только runtime-файлы приложения, этот README и manifest.json.
Отладочные PDB, исходные database.res и результаты тестов в handoff не входят.
