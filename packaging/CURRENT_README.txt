Редактор БД от Атамана

Основной комплект: C:\Dev\EvilIslands\builds\dbeditor\current.
Запуск: EvilIslands.DatabaseEditor.exe. Номер версии виден в программе.
Для этой локальной сборки требуется установленный .NET 9 Desktop Runtime.
Версия 214 ищет текстуры в фоне, поддерживает Base PAK и повторно использует данные
моделей при смене экипировки. Полная проверка содержимого ресурсов доступна через F5.
Редактор читает PAK напрямую через EvilIslands.PakReader.dll (x64), без массовой
распаковки временных файлов. Для записи нужен комплектный EIRebuild64Pack.exe.
Переносите весь комплект целиком, включая оба этих компонента.
Малахит находится в Modules; его можно обновлять независимо при закрытом редакторе.
Перед следующей сборкой закройте редактор. Пользовательские базы и проекты
храните отдельно от файлов программы. Неизвестные файлы обновление не удаляет.

Обновление: tools/Publish-Current.ps1 из исходного проекта.
Проверки и ограничения конкретной версии: work/investigations в общем workspace.
