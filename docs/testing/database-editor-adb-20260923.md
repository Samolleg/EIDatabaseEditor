The original game passes start/cycle indices as bytes, with 254/255 reserved, so new records above index 253 are not universally playable until the addon route is extended.

Implementation: a model-scoped catalog lists all ADB records and ANM clips, marking registered clips, ANM-only clips, missing clip references and indices above 253. It shows local Russian labels for orientation; they are not written to ADB. Users can edit the ADB fields and event frames, select action/stage/state with controls, or clone an existing record as a template for a saved ANM clip. New records append without reordering old indices. Added names are restricted to 15 ASCII letters/digits/underscores. Cloned event frames and their flags are cleared. Save uses the RES manager with a backup, an optimistic source-byte check and readback validation. The Kimodo default ID now fits the ADB name field; preexisting longer clip IDs remain unchanged.
