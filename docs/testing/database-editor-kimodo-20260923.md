# Генерация чернового движения Kimodo — Preview 150

## Назначение

В редакторе анимации кнопка «Создать движение по тексту…» вызывает локальный
`kmd-generate.exe` из `kimodo.cpp`. Пользователь указывает SOMA RP/SEED GGUF,
текстовый GGUF/комплект, описание действия (предпочтительно на английском),
новый ID, число кадров, шагов и seed. Kimodo не встроен в поставку редактора;
исходные веса и текстовый энкодер имеют собственные лицензии. Скачивание весов
и отправка текста в сетевой сервис не выполняются.

Выходные `root_positions.f32` и `local_rotations_xyzw.f32` принимаются только
при заявленных числе кадров и 30 суставах SOMA, точной длине файлов и конечных
числах. Выбранный исходный клип используется как шаблон набора дорожек. Создаётся
новый клип с отдельным ID; 30 суставов сводятся к 15 частям игрового гуманоида,
непредставленные суставы остаются в исходной позе. Корневое движение масштабируется
по длине ноги модели. Клип проходит повторное чтение ANM, а импорт записывается
одной операцией Undo. Пользователь может дальше править кадры и сохранить ANM
существующими командами редактора. Изменение ADB и установка в игру не выполняются.

контактов ног, визуальный результат в игре и ADB-темп не подтверждены.
Полученный клип следует считать черновиком для покадровой правки. Следующий
критерий — один реальный проход `kmd-generate` на SOMA, просмотр Human Hero,
проверка ANM в игре; если оси различаются, необходима калибровка базиса до
утверждения готовности переноса.

## Дополнение: ID клипа с начальной цифрой, Preview 157

Скриншот владельца Preview156 показывает немедленную ошибку валидатора ID до запуска Kimodo: для исходного 2hacidle01 автоматически предложено 2hacidle01_ai. CreateAnimationAsync требует [A-Za-z] первым символом. Исправлено предложение ID: начальная цифра получает префикс anim_, недопустимые символы заменяются, итог ограничен 64 символами, занятые имена получают числовой суффикс. Пример: 2hacidle01 -> anim_2hacidle01_ai. Регрессия создаёт реальный ANM-клип по предложенному ID и проверяет коллизию/длину; original database.res --animation-edit PASS, включая прежние Kimodo и сохранение ANM. При закрытом редакторе Publish-Current.ps1 обновил handoff/current до Preview157; host manifest 19/19 хэшей совпал, exe и веса Kimodo остались. Сама нейрогенерация с 60 кадрами и 20 шагами в интерактивном окне и воспроизведение в игре ещё не подтверждены.

## Дополнение: перенос движения SOMA30, Preview 158

Видео владельца Preview157: запрос `A person walks slowly forward` дал перекошенную позу вместо ходьбы. Повторили тот же запрос через установленный `kmd-generate` (60 кадров, 20 шагов, seed 1): исходный скелет стоит вертикально, ноги двигаются, корень проходит около 1,04 м по оси SOMA +Z. Старый адаптер переносил эту ось в игровую +Z (высоту), а локальные кватернионы копировал без преобразования системы координат и порядка иерархии. Скрытый рендер импорта воспроизвёл дефект.

Исправлено преобразование SOMA (Y вверх, +Z вперёд) в игровые оси (Z вверх, -Y вперёд); глобальные повороты SOMA собираются в её иерархии, затем локальные игровые повороты вычисляются для game BON local*parent. На том же реальном выводе корень движется по горизонтали, первый кадр остаётся вертикальным, руки и ноги находятся на своих местах. Регрессия проверяет ось перемещения, основные суставы, полный ANM round-trip, неизменность старых клипов и Undo. Original database.res `--animation-edit`: PASS. Игровое проигрывание нового ANM и субъективное соответствие любому произвольному тексту остаются непроверенными; качество самой модели Kimodo также ограничивает результат. При закрытом редакторе Publish-Current.ps1 обновил handoff/current до Preview158; host manifest 19/19 хэшей совпал, комплект Kimodo сохранён.
