# Kimodo seed — версия 198

При первом открытии формы seed равен `0`. Редактор до запуска Kimodo заменяет ноль криптографически выбранным положительным числом, передаёт это число в CLI и записывает в `generation.json`. Ненулевой seed передаётся без изменения. Применённый номер показывается в ходе генерации и после создания клипа или варианта; его можно вручную ввести для повтора. Последний применённый seed сохраняется отдельно от текста поля `0`, поэтому «Ещё вариант» использует следующий номер после фактического seed. После максимального `ulong` повтор начинает с `1`.

Release UiSmoke `--animation-edit` проверяет значение по умолчанию, явный и случайный seed, повтор, сохранение последнего применённого seed и показ номера в редакторе. `--kimodo-history` проверяет прежний путь записи/replay параметров. Обе проверки пройдены на DLL версии 198; реальные inference, интерфейс и игра здесь не запускались. Игровые файлы не менялись.
Ранее сохранённый вручную seed сохраняется при обновлении; для случайного выбора в таком случае установите `0` один раз.
