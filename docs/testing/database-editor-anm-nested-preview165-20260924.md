# Preview 165 — вложенная запись ANM

Задача `DBE-ANM-NESTED-WRITE-20260924`. Исходный дефект: создание, копирование и Kimodo записывали дорожки как `clip\part` в верхний каталог ANM. Предпросмотр редактора читал такой архив, но игровой клиент требует верхний ресурс `clip`, содержащий отдельный RES-каталог дорожек. В установленном `unhufe.anm` клип `twerk1` был плоским; корректный `2hascross22` — вложенным. Активные данные используются только как источник чтения.

Создание клипа теперь строит вложенный каталог. При явном сохранении или экспорте старого плоского клипа конвертируется только выбранный клип: его дорожки становятся содержимым вложенного ресурса, остальные клипы сохраняют payload побайтово. Чтение старого плоского формата остаётся. ADB и ID записей не меняются.

Проверка `--anm-layout` разбирает внешний и внутренний RES-каталоги через `ResArchiveDocument` и декодирует дорожки напрямую, независимо от `FigureAnimationSet.LoadAsync`. Она проверяет новый клип, копию, Kimodo, редактирование плоского клипа с последующей конверсией, исходные payload остальных клипов, запись и обратное чтение временных standalone ANM и ANM внутри RES с посторонним ресурсом. На копии активного `unhufe.anm` также проверена конверсия плоского `twerk1` без изменения payload других ресурсов. Итог: `ANM LAYOUT PASS`, `KIMODO PASS`.

Release UiSmoke build: 0 предупреждений и 0 ошибок. Общий `--animation-edit` дважды дошёл до новых проверок создания, копирования и Kimodo, но затем остановился на ранее зарегистрированной нестабильной проверке `ANM SAVE: no-backup left files`: рядом с файлом на короткое время появлялся `STANDALONE.ANM.ROLLBACK-*.tmp`. Причина этого стороннего временного файла не установлена; общий прогон не заявлен прошедшим. Целевой тест сохранения/формата на отдельных временных копиях прошёл. Игровое воспроизведение новой анимации владельцем ещё не проверено.

Поставка: редактор был закрыт, `tools/Publish-Current.ps1` обновил единственную постоянную папку `handoff/current` до `0.7.0-preview.165`. Манифест хоста проверен `19/19`, папки МАЛАХИТ/Kimodo сохранены (`7+19` файлов). SHA-256 активных `database.res`, `databaseJmv.res` и `figures.res` до и после совпали; игра и её ADB/ANM не изменялись. Source branch `feature/structured-list-content-builder` от `c3809f07ec3bdcb837fea17f5050cad4ca3eff9a`, изменения Preview 165 не закоммичены. Merge/push/публикации нет.
