# Preview 182 — каталог моделей из соседних RES

Исходная проблема: редактор показывал 3D-модель только через выбранную строку БД или MOB, а полного каталога ресурсов моделей из RES рядом с открытой БД не было.

Добавлена кнопка «Объекты карт из RES». Окно перечисляет все `.mod` соседних архивов, показывает источник и связанные `.bon`, позволяет фильтровать по имени и архиву и открывает модель без выбора записи БД. В просмотре отображается геометрия; текстуры, назначаемые конкретной картой, не восстанавливаются из одного MOD.

Проверка: `dotnet build tests/EvilIslands.DatabaseEditor.UiSmoke -c Release` в чистой временной копии завершился без предупреждений и ошибок. Проверка `--map-object-catalog` на установленном JamaisVu135 read-only обнаружила 147 моделей, включая все 49 `.mod` из `HDPack_Mapobjects.res`; все 49 дали геометрию и сохранили видимую сцену после событий `Loaded` и `DataContextChanged`. Живой поиск нашёл `nast9` и дал пустой список для отсутствующего имени. До и после проверки SHA-256 `database.res` и `HDPack_Mapobjects.res` не менялся. Визуальная проверка окна пользователем ещё не выполнена.

Временная сборка была подготовлена в `%TEMP%`, потому что компилятор не смог записать DLL в промежуточный каталог сборки внутри OneDrive. Готовый комплект установлен штатным `tools/Publish-Current.ps1 -PackagePath` в единственную папку `handoff/current`; манифест сверяет 19 файлов, включая неизменённые Malachite и `third-party`. Игра и её ресурсы не изменялись.
