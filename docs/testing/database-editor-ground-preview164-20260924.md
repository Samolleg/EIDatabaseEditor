# Preview 164 — опорная поверхность редактора анимаций

Задача `DBE-ANIM-GROUND-20260924`. В окне покадрового редактирования по умолчанию показана отдельная от модели сетчатая поверхность. Её высота берётся по нижней точке исходной геометрии; флажок у управления воспроизведением скрывает и отключает поверхность. Перетаскивание корня и стоп ограничено по высоте, движение вдоль поверхности остаётся свободным. При включённом флажке фиксация стопы и контакт диапазона ставят опору на эту поверхность. При выключенном флажке сохраняется прежняя фиксация в текущей мировой позиции. Настройка включена в проект `.eianim`; старые проекты без этого поля открываются с поверхностью.

Отображение поверхности само по себе не правит ANM и не создаёт игровые коллизии. Уже существующие клипы не меняются автоматически: ограничение действует при ручной правке. Привязка стопы к поверхности действует при следующем применении позы или жесте; соответствие анимации физике игры не проверялось.

Проверки: Release UiSmoke собран с 0 предупреждений и 0 ошибок. `--animation-edit` на установленной модовой БД два последовательных запуска после итогового изменения прошёл: Human Hero, GZOrcMaleF6 и BatDarkM12, покадровые операции, сохранение ANM, IK, жесты, roundtrip проекта; добавлена проверка видимости и отключения поверхности, ограничения корня и стопы, свободного движения вдоль неё. В двух более ранних запусках проявился нестабильный сбой старой проверки `ANM SAVE: no-backup left files`; код сохранения не менялся. После расширения сообщения диагностики два полных прогона прошли. Причина сбоя остаётся открытой отдельной задачей.

Итоговая поставка через `tools/Publish-Current.ps1` при закрытом редакторе: `handoff/current`, `0.7.0-preview.164`; манифест хоста 19/19, МАЛАХИТ и Kimodo 26/26 без изменений, контрольный `database.res` игры без изменений. Коммита, merge, push и установки в игру нет. Требуется ручная проверка масштаба/видимости сетки, постановки стопы на поверхность и редактирования позы в окне.
