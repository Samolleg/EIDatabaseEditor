`work/investigations/dbe-animation-kimodo-fixes-20260929/REPORT.md`

Проверяемые контракты:

1. `.eianim` открывает неизменённый, собственный сохранённый и новый/Kimodo-клип
   только из проекта; возвращает Undo/Redo и настройки. Несовместимую модель/скелет
   отвергает, внешний конфликт ANM допускает только к восстановлению/экспорту.
   V1 остаётся читаемым на точном исходном ANM.
2. При MotionPins операции диапазона и высоты, прямое изменение позы и импорт
   не двигают закреплённую стопу: невозможная операция отклоняется без изменения
   байтов/истории, после снятия pin проходит и отменяется/повторяется.
3. Kimodo сохраняет prompt/raw/параметры и hashes генератора/весов перед импортом;
   при отказе оставляет исходную анимацию, статус/причину/путь, повторяет импорт
   без инференса. Предварительная проверка отвергает чужой скелет до запуска.
