# Поиск формы оружия и брони — версия 206

Запрос: в редакторе экипировки отсутствует поиск по русскому названию или модели.
Причина: ComboBox выполнял только встроенный переход по началу `DisplayText`,
который начинается техническим именем. Отдельного фильтра и модельных метаданных
в списке форм не было.

## Изменение

- Поле высотой 28 добавлено над формой оружия/брони в общем структурном
  конструкторе. Поиск по подстрокам и нескольким словам в любом порядке учитывает
  техническое имя, названия RU для всех совместимых материалов, модельные коды
  из класса/индекса формы в БД; регистр и `ё`/`е` не различаются.
- Броня одновременно фильтруется по существующему выбранному типу/слоту.
- Полный список хранится отдельно от видимых совпадений. Поиск сохраняет
  выбранную форму, материал, значения списка и текущий предпросмотр. Если
  выбранная форма не совпадает с запросом, она остаётся отдельным пунктом;
  счётчик учитывает только совпадения. Пустой результат объяснён явно.
- Очистка × возвращает полный список в выбранном типе брони. Down/Enter
  открывают список из поиска; Escape в заполненном поиске сначала очищает его.
  Подсказка формы показывает модельные коды. Локализация после выбора материала
  сохраняет запрос и полный набор форм.

Исходники:
`Core/EmbeddedMagicCatalog.cs`, `App/Models/EmbeddedMagicEditorContext.cs`,
`App/Dialogs/StructuredStringListEditorDialog.{xaml,xaml.cs,Equipment.cs,ShapeSearch.cs}`
в `src/EvilIslands.DatabaseEditor.*`; редакционная версия в `Directory.Build.props`.
Точные исходные/итоговые SHA и локальный diff находятся в
`work/investigations/equipment-shape-search-20261008/`.
