# Поиск анимаций в модели — Preview 166

Выполнено: в списке ANM показаны ID, русское имя и фактический индекс записи ADB выбранной модели. Несколько записей одного клипа перечисляются вместе. Для клипа без записи показано «не прописана в ADB», а при недоступном источнике — «ADB недоступен». Поиск принимает ID, русское имя или номер; ввод не меняет текущую позу.

Автоматическая проверка: `EvilIslands.DatabaseEditor.UiSmoke.dll --animation-search <database.res>` загружает модель из БД и проверяет построение списка по настоящим ANM/ADB, фильтр по трём полям, пустую и отсутствующую ADB, а также сохранение выбранного клипа при фильтрации и возврат списка после очистки.

Ручная проверка в редакторе: открыть модель Human Hero, выбрать «Модель», раскрыть список анимаций, найти клип по части ID и номеру ADB, очистить поиск, затем открыть «Игровой список ADB» и проверить обновление подписи после его сохранения. Проверка в игре для этой UI-доработки не проводилась.

Preview 167 после пользовательского видео: прежняя проверка не охватывала поиск клипа другой модели. В записи выбран `GZOrcFemaleF4` (`unorfe`), а `twerk1` принадлежит `unhufe`; поэтому локальный результат 0 был технически верен, но интерфейс не объяснял причину. Новый поиск читает каталоги ANM/ADB других моделей в той же папке ресурсов в фоне и показывает модель-владельца и номер ADB. Регрессия `--animation-search` теперь воспроизводит именно `GZOrcFemaleF4` + `twer`, требует видимую после компоновки подсказку о `twerk1`/`unhufe`/ADB и сохраняет исходную позу орчихи. Неподходящий чужой клип в текущем селекторе не выбирается. Поиск по другим моделям ограничен каталогами RES в папке текущего ANM; внешние папки игры он не индексирует.

Preview 168 после повторного видео: открытый ComboBox перехватывал фокус у строки поиска и выдача становилась устаревшей или исчезала. Результаты вынесены в отдельный список под управлением: они обновляются при каждом изменении текста, клипы текущей модели выбираются щелчком или Enter, Esc очищает поиск. Однобуквенный запрос `d` больше не совпадает со служебным текстом `ADB` каждой строки; номера ADB ищутся числовым запросом. UI-регрессия проверяет два последовательных разных запроса, отсутствие открытого ComboBox, щелчок по результату и фактическую загрузку клипа, очистку, а также `GZOrcFemaleF4` + `twer` в отрисованном окне. Игровое воспроизведение этим тестом не проверяется.
